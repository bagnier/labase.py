Notes — Smart filters: each pill opens a text field and narrows its matches as you type (org shown open above); the default all is muted+italic (filter inactive), a chosen value is bold (active) with an ✕ to clear. Filters (all combine): date slice · source · level · org_id · user_id · request_id · free text. Columns are sortable (click a header); default is Time ▼ (newest first). Org shows — when a line has no org (background app logs). Request id is the correlation pivot (click to pin). At the default WARNING, request.* (info) lines are absent until an admin lowers the level; audit & issue rows always show (read from their tables, not the firehose file).
